# Pass 1 — 叙事架构（Narrative architecture）

七个决策组（decision groups）。每组列出实测的人类对 AI 差距、**生成（generate）**时做什么、**修订（revise）**时查什么。数字来自 StoryScope（S）、Beguš 2024（B）、Xu et al. PNAS 2025（X）、Nonaka & Perry 2025（N）、QUDsim（Q），以及点名它的那一行所引的 Rohrbacher et al. 2026（台账键 `ROHRBACHER-2026`，按 ID 引用）；百分比与频率按*人类 vs AI* 读。稳定的来源身份存于仓库研究台账（research ledger）；本文件中的单字母别名是文件局部的。除非被引来源明确测过该干预，Generate/Revise 处方均为 sepia 的设计推断。

填架构图模板（architecture sheet）时过全部七个组，但**每篇故事只执行 3–5 个偏人类的手法**（见 humanizer SKILL.md 校准三原则）。标 ⚑ 的组在仓库 2026-08-27 生态快照（ecosystem snapshot）所采样的工具中缺席；把这当作有边界的产品观察，而不是普遍零覆盖的证明。

**按档授权（v7）**：本 pass 的结构类条款（结局三脚架拆解、时间结构选择、rarity move、副线配置）与 `draw-sheet.md` 的 structure_band 联动——**档 1-2**：跳过架构图的后三组设计项（结局弧、时间编织、罕见手法），线性直叙即是合法形态；**档 3**：允许一处结构回扣 + 半收尾，rarity move 可选；**档 4-5**：全部七组生效，rarity move 照常「恰好一个」。低档跳过的组不按缺失计缺陷（自检的按档授权行）。

起草前填本表（工作流 A / Workflow A），或作为诊断摘要填（工作流 B / Workflow B）：

| 决策 | 本篇的选择 | 目标带 |
|---|---|---|
| 主题处理 | 明说 / 暗示 / 不给出 | 默认暗示 |
| 副线（subplot） | 无 / 平行 / 对照 / 独立 | 一条副线，约 40% 的故事 |
| 解决驱动 | 主角选择 / 混合 / 外部 | 混合或外部约 50% |
| 结局模式 | 外部行动 / 内心接受 / 部分解决 / 开放 / 灾难性 | 避开「内心接受」默认 |
| 时间结构 | 线性 / 中度非时序 / 编织 | 中度（1–5 量表上的 2–3） |
| 揭示节奏 | 前置 / 均匀 / 后置 | 后置 |
| 情绪策略 | 混用：直接命名 / 行为 / 身体化 / 模糊 | 行为主导的混用；身体化只用于峰值 |
| 主角出场方式 | 描写 / 行动中 / 对话中 / 念头 / 他人转述 | 对话中或行动中 |
| 对主角的道德立场 | 肯定 / 悲剧缺陷 / 暧昧 / 反英雄 | 暧昧约 60% |
| 现实世界锚点 | 列出要点名的真实作品、地点、品牌 | ≥1 个明确的具名引用 |
| 网络形状 | 谁从不与谁见面；谁讨厌谁 | 稀疏，情感净值中性 |
| 罕见手法（rarity move） | 对本题材在结构上反常规的那一个选择 | 恰好一个 |

## 1 ⚑ 主题：停止解释它

| 特征 | 人类 | AI |
|---|---|---|
| 叙述者明确说出主题（S） | 52% | 77% |
| 主题显豁度，1–5（S） | 3.28 | 3.94 |
| 对话被用于哲学辩论（S） | 34% | 59% |
| 道德/哲学权重，1–5（S） | 3.26 | 3.68 |
| 主题统一度，1–5（S） | 4.41 | 4.74 |

中文示例（小说向）：

- AI 味：「多年以后他才明白，那条河带走的不是祖母的骨灰，而是一个时代。」——叙述者出面替读者总结主题。
- 偏人类：全篇只写弟弟每次返程都把母亲腌的萝卜干塞满包，从不写他想家；结尾停在高铁上他拧开瓶盖又拧上，仅此一笔。
- 对话做情节与关系的事：姐妹俩吵的是「妈的存折到底在谁那」，不是「何为亲情」。

**生成（Generate）：** 先定下主题，然后信任事件自己去承载它。叙述者从不总结教训；悲伤中的角色的弧线**不**以「她学到了什么」收尾。对话承担情节与关系的工作——角色吵的是房租，不是悲伤的本质。让一个场景或意象纯粹为质感存在，不服务任何主题（人类在统一度上得分 4.4/5，不是 5/5——接近完全的统一是指纹，完全的统一更糟）。

**修订（Revise）：** 搜最后三段和一切叙述者概化（「人就是这样」「直到那时她才明白……」「到头来，重要的是……」）——删掉，或改成一个具体动作或意象。凡对话在辩论观念处，改写到分歧落在角色各自想要的某个具体东西上。若文中解释了某个象征，删掉解释，留下象征。

> Beguš 报告受测模型故事里反复出现道德说教式结尾句，如「爱没有边界」（"love knows no boundaries"）。把该模式当作候选信号，而不是「断言式结尾必然出自机器写作」的证据。

## 2 ⚑ 情节：放松单轨

| 特征 | 人类 | AI |
|---|---|---|
| 完全没有副线（S） | 57% | 79% |
| 副线与主线主题平行（S） | 42% | 21% |
| 因果链连续性，1–5（S） | 3.92 | 4.20 |
| 再生成时复现的情节元素占比——「drop ratio」（X） | 3.7% | 9–11% |

中文示例（小说向）：单轨到底——「下岗→摆摊→遇贵人→开店成功」一链直通；偏人类——主线下岗再就业，中间插一条楼下修车摊主给女儿攒学费的平行线，斜着照应主题、最后不收拢。

**生成（Generate）：** 大约五分之二的故事给一条副线；有副线时，让它斜着回声主主题，而不是复述它。允许因果链断一次：一个不是由激发事件导致的小插曲，一个从幕后到来的后果。埋一个永不引爆的细节——人类留线头；每个伏笔都全额兑现的道具清单是机器记账。

**修订（Revise）：** 把稿子提纲成节拍清单（beat list）。若每个节拍都被上一拍导致、一条不断线直通高潮，砍断一环：把某个原因挪到幕后，或插一个有自己起因的事件。若故事没有第二条线、而篇幅载得动，编一条进去。

**回声测试（Echo test，X）：** 对每个转折点问——*如果这个题材再生成二十次，同样的转折还会出现吗？* 乐于助人的陌生人、被干净利落解决的难题、按点到来的和解：这些都会复现。把必然的转折换成需要本篇具体细节才成立的转折。卡夫卡笔下的交通警察说「放弃吧！」然后走开；二十次再生成会产出二十个指路的警察。

## 3 结局与解决

| 特征 | 人类 | AI |
|---|---|---|
| 解决由主角自己的选择驱动（S） | 46% | 69% |
| 经由内心理解/接受而解决（S） | 27% | 47% |
| 道德上暧昧的主角（S） | 59% | 38% |

中文示例（小说向）：AI 式三脚架——「经过这一切，她终于成长了，选择了原谅，也与自己和解」；偏人类——事件上他争到了房子，行为上他骗了亲哥，结尾不给道德结账。

**生成（Generate）：** 不要默认「主角成长后自己选择解决并与命运和解」这条弧——这个复合默认（能动+接受+成长）是数据里最强的结局指纹。一半的时间，让运气、别人或机构决定结局。结局可以是部分的、开放的、或灾难性的。主角最后的道德位置可以保持混合：在事件上赢了，在行为上错了。

**修订（Revise）：** 若稿子以「主角决定+接受+理解」收尾，至少换掉这个三脚架的一条腿。砍掉把每笔账都结清的收场白段落；在感觉完整之前**早一拍**收尾，通常就是修法。

## 4 ⚑ 时间：线性是选择，不是默认

| 特征 | 人类 | AI |
|---|---|---|
| 时序不连续，1–5（S） | 2.40 | 2.12 |
| 非时序（闪回/闪前）强度，1–5（S） | 2.58 | 2.31 |
| 用非线性框架延迟披露，1–5（S） | 1.96 | 1.68 |
| 揭示之后对前文的再语境化深度，1–5（S） | 3.28 | 2.95 |
| 揭示节奏（人类指纹，S） | 后置 | 均匀/前置 |

中文示例（小说向）：人类带——开篇是出殡，故事往回绕四十年，直到最后才交代死者年轻时那桩事，旧场景因此全部变色；AI 味——从祖辈讲起，把人物背景全部交代完毕故事才开始动。

**生成（Generate）：** 人类带是*中度*非线性——一个从葬礼开场、向几十年前盘旋回去的故事，不是打乱的魔方盒。用时间跳跃**给信息安排舞台**：扣住原因，从结果开场。揭示瞄准到能迫使重读——最好的反转给早先的场景重新上色（目标 3/5；既不是什么也不改变的反转，也不是全部推翻）。最大的披露留在后面（后置节奏是实测的人类指纹）。

**修订（Revise）：** 若稿子按「第一因到最终果」顺叙，找出那个扣住不写冲击力反而变大的场景，把它挪动。检查是否存在 DeepSeek 式前置（全部背景在故事开始动之前交付完毕）：砍掉汇报段落，让背景在行进中漏出来。

## 5 ⚑ 情绪与感官：打破「展示不要讲述」的教条

| 特征 | 人类 | AI |
|---|---|---|
| 情绪主要经身体化感觉/隐喻传达（S） | 38% | 81% |
| 情绪主要经直接命名传达（S） | 29% | 8% |
| 嗅觉意象位于主导感官之列（S） | 57% | 82% |
| 环境映照人物内心状态，1–5（S） | 3.58 | 4.07 |
| 开篇句归类为「感知空间」、环境为情绪氛围而被感知（`ROHRBACHER-2026`；英语，归一化频率，GPT 4.1；其余三个受测模型同样高于人类） | ~0.19 | ~0.47 |
| 感官密度，1–5（S） | 3.66 | 3.93 |
| 内心通达深度，1–5（S） | 3.67 | 3.93 |

中文示例（小说向）：AI 味——「恐惧攫住了她：心脏擂鼓，手心冒汗，走廊尽头的灯忽然暗了下来。」；偏人类——「她怕了。」／「筷子放下又拿起，最终没伸向那碟菜。」；让天气只是天气：暴雨就是袜子湿了，不必每场雨都隐喻婚姻。

**生成（Generate）：** AI 把「展示不要讲述」执行成了教条：恐惧永远是胸口发紧、冷汗、变暗的灯光。人类混用四种模式，偏重最平实的两种——行为第一，直白命名第二（「她怕了」是人类会写的句子，模型几乎从不写）。身体化渲染每篇只留给一到两个峰值。让天气只是天气：不是每场暴雨都承载婚姻。配给气味——它已经成了机器散文的鉴赏家感官。把环境落在行动空间（action space，人物穿行其中、拿取东西的地方），而非感知空间（perceived space，为情绪氛围而被感知的地方）。人类基线里行动空间是最常见的空间模式；四个受测模型（GPT 4.1、LlaMA 3.3、Mistral 3.2、Gemma 3）的英语开篇全部把感知空间写到人类水平之上，GPT 4.1 约为其两倍（`ROHRBACHER-2026`）。

**修订（Revise）：** 给每个情绪节拍清点并归类其模式。若身体化主导，把多数改成行为（她做了什么）或直白陈述（她感到什么，点名），只保留最强的一两处身体化。剥离连续数场景环境影随心情的移情景语（pathetic fallacy）。把感官描写削向中等密度——三感句砍掉第三感。按功能给环境句分类：为情绪氛围而被感知（感知空间）、被穿行其中或拿取东西的人物使用（行动空间）、或两者皆非（静止视点看出去的空间，或平实描写）；该研究对其五个类别全部作了归类，此处只比较这两类，因为它报告的差距就在这两类之间。若「被感知」压过「被使用」，把多数感知句改成使用句，两者皆非的句子不动；上文保留的一两处身体化峰值可以留在感知侧。

## 6 ⚑ 角色与社交网络

| 特征 | 人类 | AI |
|---|---|---|
| 主角经外部描写出场（S） | 30% | 52% |
| 人类指纹：对话中出场（S） | 最强的人类标记 | 罕见 |
| 网络密度——发生互动的角色对占比（N） | 0.18 | 0.34–0.47 |
| 关系情感均值（N） | −0.06（净值中性） | +0.24 到 +0.66（全为正） |
| 敌对关系中的聚类（N） | 0.395 | 0.07–0.21 |
| 把角色置于危险之前先建立投资，1–5（S） | 2.76 | 2.99 |

中文示例（小说向）：描写出场（AI 味）——「他身材高大，剑眉星目，浑身散发着生人勿近的气场。」；行动/对话出场（偏人类）——「『结账。』他拍下十块钱，没抬头。」；敌对有结构——反派那边师门内讧、盟友倒戈，而不是一根独自指向主角的仇恨指针；与情节无关的厌恶——二姨就是看不上三叔，跟遗产没关系。

**生成（Generate）：** 让主角在说话或做事中登场，而不是被描写（「那条狗是周二来的」胜过一段外貌与身世）。保持角色图稀疏：有些人从不相遇；有些人只通过第三人认识。关系情感总值应接近中性——真实的角色群里有与情节毫无关系的厌恶。给敌意*结构*：反派有盟友、有内部分裂、有自己的网络——不是一个独自指向主角的孤立敌意节点。让读者几乎还不认识的角色陷入危险，也没关系。

**修订（Revise）：** 画出带正负号的边的角色图。若人人连着人人，删边。若每条边都温暖，把几条调凉。若反派是孤立的，给他们一段与主角无关的关系。

**细节功能配平（v7，实测教训）**：保护资产条款（人→动作→场景具体链）提供的是**正功能细节**——它们让具体性在场；但「每一个细节都恰好服务主题」被评审定罪为「为证明真实感而主动提供证据」。本 pass 要求正功能细节与**非功能细节**同时在场（与 draw sheet 的 non_goal_details 配额联动）：非功能=不服务主题、不承担文学功能、只承担记忆功能的物件/旁枝/无解释的偏好（第 6 组的「与情节无关的厌恶」是其关系形态——本条是其物件形态）。自查：全文细节逐条标「功能/非功能」，全部为功能即返工。

## 7 ⚑ 外部世界与读者

| 特征 | 人类 | AI |
|---|---|---|
| 对真实文本/作者的明确具名引用（S） | 47% | 24% |
| 明确+隐含引用的均衡混用（S） | 37% | 16% |
| 任何第四堵墙可渗透性（S） | 67% | 39% |
| 直接对读者说话（S） | 28% | 7% |
| 有意义的独立地点数（S，序数量表） | 1.34 | 1.08 |
| 对话对叙述之比，1–5（S） | 2.95 | 2.70 |

中文示例（小说向）：具名——「书架上那本卷了边的《活着》」，不是「一本著名的小说」；读者旁白——「你知道那种筒子楼，楼道永远比屋里亮」；地点多一两处——不只有出租屋和公司，还有批发市场与长途汽车站。

**生成（Generate）：** 点名真实事物——书架上真实存在的小说、真实的乐队、具体的那条公路（humanizer SKILL.md 硬护栏适用：只写真实、正确的引用；需要素材时向用户要）。具名引用与不点名回声混用。偶尔一句承认读者存在的旁白（「你知道那种房子」）是人类手法——*偶尔*：一两句旁白，不是元小说框架。让场景发生在比题材严格需要多一到两处的地方。让对话比背景交代稍多占些地盘。

**修订（Revise）：** 若稿子指涉「一位著名诗人」或「一首老歌」，把其中一个换成具体且真实的。若故事在一个房间里待了五千字而题材并不要求幽闭，把一场戏搬走。处处模糊用典=机器式的谨慎。

## 罕见手法（rarity move）

人类故事在结构上比 AI 故事更*罕见*（rarity percentile 罕见度百分位 0.71 vs 0.49；五个模型聚在叙事空间的同一个区域，人类散布各处）。在上述按带校准的规则之外，做出**恰好一个（exactly one）**对本题材而言真正反常规的结构选择——一个出人意料的叙述距离、一个该类型罕用的解决模式、一个把类型重铸的框架（跨类型的文学野心是实测的人类指纹）。一个。多于一个读起来像表演。

中文示例（小说向）：豪门恩怨题材，通篇只用家族群聊天记录与朋友圈截图拼出（书信体/文档体对该类型是反常规选择）；职场升职文让一个从未露面的被裁者担任叙述者。
