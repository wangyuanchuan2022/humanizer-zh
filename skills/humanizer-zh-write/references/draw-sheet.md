# 抽签表（draw sheet）——脚本化随机性的执行契约

> 本文件是 `draw-sheet.mjs` 的**契约文档**：字段、参数带、纪律。两者键名以本文 D.2 契约为单一事实源（改本文件必同步改脚本，verify 锚点同时锚两侧）。
> v7.1 增量（四判据 → 四轴）：随机化从**数量层**扩展到**位置、形态、有无**三层；新带值来自 32 篇人臂语义标注实测（`../../v7.1-plan/bands-v2-annotation.md`，2026-09-21——部署包内为相对上溯路径，仓库内为 `humanizer-optimize/v7.1-plan/`）。
> 依据：《humanizer 技能改进分析报告》§四主轴一 + 附录 D。核心论断：**确定性规则会把特征取值的离散度压平——真人写作的判别性不在单条特征上，而在离散度上**（实测：跨篇模具复用 6/12/4 处、错字同簇六例、句长/段长 SD 低于真人 37-45%）。

## D.1 五原则

1. **随机源固定且落盘**：每篇一份 draw sheet（JSON）含 seed；同 seed + 同 genre + 同 index 重跑得**逐字节一致**的结果 → 可复现、可审计、可回归。
2. **抽签只决定「用哪些手法、取值多少、结构多紧」，不决定内容**：内容仍受题材与事实约束（守主路由「永不编造具体信息」硬护栏）。
3. **带内抽样，禁锁点值**：取值来自 D.3 的人类分布带；**禁止把带的中位数当默认值**——「每篇都取中位」等于把随机性改回确定性。
4. **批级自检**：一批（≥3 篇）生成后，统计抽签结果分布是否覆盖带的多个取值，并跑跨篇模具复用检测（selfcheck 批级自检节）。
5. **位置与有无也随机化（v7.1）**：数量随机而位置/有无恒定仍是指纹（实测人臂噪声有位置结构：非目标细节偏前、坏痕偏后）——噪声落点、金句位、链长、坏痕有无/形态全部带权抽签；**篇级保证全部移到批级**（D.10 六约束）。

## D.2 十二字段契约（JSON；v7.1 = 九字段 + noise_position/power_position/chain_length，quotas 增 meaningless_badness）

```json
{
  "seed": 20260921,              // 随机种子（日期或任意整数；须随稿落盘）
  "genre": "en-tech",            // 六文体之一
  "structure_band": 2,           // 结构强度档 1-5（见 D.6；体裁上限：应用文≤4、口语体≤3）
  "moves": ["announced_doubt", "background_aside"],   // 本次启用的手法（12 池内抽 3-5，禁抽满、禁跨篇复用）
  "quotas": {                    // 配额实际取值（带内抽，禁点值）
    "aphorism_total": 1,         // 警句总数（带 0-2）
    "plain_paragraph": 2,        // 无发力平实段落数
    "first_person_per_1k": 3,    // 第一人称/千字
    "digits_per_1k": 5,          // 具体数字/千字
    "hard_typos": 1,             // 错字处数（带 0-3，允许 0）
    "typo_types": ["homophone"], // 错字类型（抽签：同音/形近/漏字/语序/标点）
    "non_goal_details": 0,       // 非指向细节（v7.1：0 加权文体分——essay P(0)=0.42 / doc P(0)=0.90 / s2 P(0)=0.83，见 D.4b）
    "half_used_sources": 1,      // 半用材料（≥1：引了只用一半/结论未采纳；v7.1 未重测维持）
    "coinage": 1,                // 自造复合词/新造语（带 0-2，禁令上限 2，可为 0）
    "extended_metaphor": 0,      // 巧喻装置（带 0-1，可为 0——有时抽到 0 个）
    "meaningless_badness": {     // 无意义坏痕族（v7.1 判据④：不迷人的、无功能的坏）
      "present": true, "count": 1,
      "form": "冗余重述",         // 五形态池抽（D.10；实测形态，预设四形态零实证不收录）
      "para_zone": "back"        // 篇内三分位（实测坏痕偏后 .17/.33/.50）
    }
  },
  "noise_position": {             // v7.1 判据②：噪声落点（配额为 0 时字段为 null，语义=不适用）
    "non_goal_zone": "front",     // 非目标细节篇内位（实测偏前 .58/.25/.17——背景铺垫性）
    "badness_zone": "back",       // 坏痕篇内位（实测偏后——后段不打磨）
    "cluster_when_two": true      // count≥2 时允许同段/相邻段聚集（实测 2/2 聚集；P=0.5 抽）
  },
  "power_position": {             // v7.1 判据③：金句段内位（配额为 0 时 null）
    "coinage_pos": "middle",      // end/middle/start 按文体实测权重（人臂 end 仅 52%，非 100%）
    "aphorism_pos": "end"
  },
  "chain_length": 1,              // v7.1 判据①④：物件链长 1/2/3（.57/.27/.16——孤儿细节是常态，完整链是少数）
  "ending_mode": "object_stop",   // close | half_close | open | object_stop（按体裁白名单抽：zh-doc 排除 open、zh-s2 排除 close，其余全池）
  "length_target": 780,           // 篇长目标（从该文体真人长度带抽，含 SD）
  "used_before": [],              // 同批已用句式模具（台账，禁复用）
  "notes": "档 2：仅一处结构动作（单点留白）；不设回环"
}
```

**执行纪律（write 操作）**：动笔前先出签——运行 `references/draw-sheet.mjs`（单篇 `node draw-sheet.mjs --seed <N> --genre <G> [--index <I>]`；批量 `--batch <g1,g2,...>` 输出 JSONL 且六条批级约束在生成器内强制，见 D.10）照签执行；**draw sheet 随稿落盘**（含 seed 与实际取值）。无 shell 环境降级为**表格自抽 + 显式留痕**（在稿前写下十二字段取值与理由，效力等同）。review/refactor 操作**不强制抽签**（诊断对象是既有文本）。

## D.4 手法池（moves；从「评审实证双清单」的有效手法提取）

| 手法名 | 内容 | 实证依据（评审原话节选） |
|---|---|---|
| `announced_doubt` | 主动交代不确定性／记忆模糊（"数字是估的"/"记不清哪年"/"it's round because I rounded"） | 判真人 HZ 篇的致胜证据；ChatGPT 判据 12 |
| `anticlimactic_close` | 反高潮／拒绝升华收尾 | `refused-thematic-summary` / `no-epiphany-ending` |
| `non_goal_detail` | 无用私人细节（不服务主题、不承担文学功能；"1215. Sandwich."） | `idiosyncratic-period-detail`；ChatGPT 判据 1 |
| `self_deprecation` | 自曝短板／愧疚（"improved the PR in every way except the one that mattered"） | `lingering guilt confession` |
| `life_runoff` | 生活流水与杂质（消费明细/错字/路人引语/物件收尾） | 消费明细流水、物件收尾（关东煮） |
| `plain_colloquial_close` | 平实口语收束（事实回扣收尾/对话收） | 「事实回扣收尾」「平实收尾」 |
| `texture_local` | 地域与实物纹理（Brookshire's / Culver's / ginja 巧克力杯） | 英文席点名认可 |
| `background_aside` | 背景铺垫不承重（受众/时代/事件背景，删后论证不损） | Phase A 语义标注：essay 类 non_goal 六处的主形态（老龄标准推迟/里约筹备/B站背景） |
| `stray_fact` | 无关冷知识/边角事实，说了不回收 | Phase A：zh-s2-004 猪体脂率（引文抽查命中）/ zh-s2-019 清洁工一瞥 |
| `object_orphan` | 提及即弃的具体物件（与 chain_length=1 联动） | Phase A：链长 1 占 57%（n=67），zh-s2 物件最丰（3.25/篇） |
| `number_idle` | 例行数字自然在场不承重（人数/批次/金额） | eval-v5 判 HUMAN 依据「耗材与金额级颗粒度」+ D.4b 应用文条款 |
| `dialogue_quote` | 直接引语（当事人原话直录） | eval-v5 zh-doc 席判 HUMAN 高频依据（孩子/老人/老板娘原话） |

**改造条款（允许→带随机配额）**：Deferred／不闭环／瑕疵事件等既有「允许」类手法，v7 起进入 moves 池参加抽签——**只有成为配额才会稳定出现**（实测：判真人的 HZ 篇几乎都做了这些，但做与不做取决于模型当次发挥，跨篇出现率不稳定）。

**记忆模糊专项（A3.3）**：`announced_doubt` 进池（上表首行）；**禁全篇精确时间线**——同篇内至少一处时间/数字以模糊形态出现（约/大概/哪年来着/记不清），抽到本手法时执行。

## D.4b 细节与文献的非全指向性（三档配额）

**问题**：AI 让每个细节、每条引文都服务于主旨——「每一个细节单独看都合理，但放在一起有一种作者为了证明自己经历过这件事而主动提供证据的感觉」（外部评审原话）；应用文评审的 AI 判据同样写着「数字密铺且每处细节均承重」。真人反思文常见的恰恰相反：**引了但只用一半、提到就搁下、材料与主旨只部分相关**。

| 配额 | 要求 | 例 |
|---|---|---|
| **非指向配额**（non_goal_details，v7.1 改 0 加权文体分化） | 有无与数量按文体实测概率抽（见下）——**「每篇必有」本身是失真信号** | 提及某书某事后搁下不回收；写一段与主题无关的侧枝 |
| **半用配额**（half_used_sources，带 [1,2]） | ≥1 处文献/数据**只被部分使用** | 引了某观点但结论未采纳；提出材料后自我怀疑「这个例子其实也可以反过来说」 |
| **未消化痕迹**（随 half_used 出现，非独立配额） | 允许未完成处理 | 「这本书我其实没读完」「这段我到现在也没想明白」「当时记的笔记现在看不懂了」 |

**v7.1 文体分化（Phase A 实测，n=32 双席标注）**：非指向在场率实测 zh-essay 58%（非零时 1-3 处）/ zh-doc **0%（8/8 全零，双席独立一致）**/ zh-s2 17%——抽签实现为 P(0) 加权：essay 0.42 / doc 0.90（用户拍板低概率保留，非硬移除）/ s2 0.83；EN 三文体暂用 zh 全局临时值 0.72（待 EN 标注批校准）。**篇级「≥1」保证已废除**——批级保证见 D.10 约束 3。

**文体专项**：
- **反思/议论文（zh-essay / en-essay）**：**文献不必全部指向主旨**——材料的价值可以是它的存在本身，而非它对论点的支撑；引用后搁置、部分采纳、提出后存疑都是合法形态。
- **应用文（zh-doc）**：数字与事实不必每处承重；允许与结论无关的例行数据（人数、时间、批次）自然在场。
- **小说（en-fiction / 中文小说）**：与「保护资产条款」配平——保护资产要求的「人→动作→场景具体链」是**正功能细节**，本配额要求的是**非功能细节**，两者须同时存在（实测：判真人的 HZ 篇普遍有非功能细节，被判 AI 的普遍没有）。

**执行**：抽签时 non_goal_details/half_used_sources 已在 quotas 输出（前者 0 加权，落点看 noise_position.non_goal_zone）；写作时落实为具体材料选择，自检时人工核对「非指向是否实质」（装饰性跑题不算）。

## D.10 位置参数与批级六约束（v7.1 四轴落地）

**为什么位置也要随机**：v7 的抽签只随机化数量，位置由写作会话默认安排——结果噪声均匀铺洒（每段一个钩子）、金句总落发力位。Phase A 实测人臂噪声有**位置结构**：非目标细节偏前（58%/25%/17%，背景铺垫性）、坏痕偏后（17%/33%/50%，后段越写越不打磨）——**两类噪声互补，均匀分布本身就是指纹**。

**四参数语义**（D.2 契约新三字段 + 坏痕族；带值全部实测，源=语义标注带层）：

| 参数 | 取值（实测权重） | 执行语义 |
|---|---|---|
| noise_position.non_goal_zone | front .58 / mid .25 / back .17 | 非目标细节落点（篇内三分位） |
| noise_position.badness_zone | front .17 / mid .33 / back .50 | 坏痕落点 |
| noise_position.cluster_when_two | count≥2 时 P=0.5 | 允许两处挤同段/相邻段（实测 2/2 聚集） |
| power_position（coinage_pos / aphorism_pos） | end/middle/start 按文体：essay .58/.28/.14、doc .56/.39/.06、s2 .44/.44/.12 | 金句段内位——**人臂 end 仅 52%**，middle/start 合计近半；middle/start 位的实现=埋在段中前后皆平句、或出现后紧接平淡句自我削弱（undercut）；**end 位不得连续两段出现** |
| chain_length | 1:.57 / 2:.27 / 3:.16 | 物件细节复现次数——**孤儿细节（提了不回收）是常态，完整链是少数** |
| quotas.meaningless_badness | P(在场)：doc .75 / s2 .50 / essay .25；count [1,2]；形态五池抽 | **不迷人的、无功能的坏**（判据=编辑必改+无功能）；形态池=Phase A 实测 18 处：冗余重述／语法杂糅（并列崩坏·双重因果·双重否定）／词语粘连重复／事实性自相矛盾（时间·数量冲突）／成语误用。与既有瑕疵手法（self_deprecation、announced_doubt 等**迷人的坏**）的分界：有叙事/防御功能的瑕疵不属本配额；错别字与文体惯例排除 |

**批级六约束**（`--batch g1,g2,...` 在生成器内强制，违反整批换 attempt 重抽、50 次耗尽 fail-loud；单篇模式不检，批级复核归 selfcheck 批级自检）：

1. 任意两篇 moves 交集 ≤2（池 12 时两两期望 ~1.3）；
2. **四轴在场率 ≤ floor(3N/5)**：坏痕在场 / 金句非 end 位 / 链长 3 / 噪声聚集——修复轴本身是新潜在指纹（防过矫对称律：v7 死于「5/5 都有 non_goal」，v7.1 不得死于「5/5 都埋金句留悬线」）；
3. essay 批级保证：nEssay≥3 时 ≥ceil(nEssay·2/5) 篇 non_goal>0（doc 全零合法——实测即全零）；
4. 布局分布：≥2 篇有效时 non_goal_zone / badness_zone 不得全同；
5. 坏痕形态批内不复用（同形态最多 1 篇）；
6. **防过矫单篇**：单篇 ≥3 轴活跃即重抽（四轴特征同篇齐装=新的设计感）。

EN 三文体：本节全部参数暂用 zh 全局临时值（schema 决策 2026-09-21：EN 用 zh 全局临时值），EN 标注批后校准。

## D.5 与既有条款的三关系

1. 本机制**不新增禁令**，而是把既有条款（W0 系列配额、九测、保护资产、Deferred 等）的值域**从点值改为可抽样的带**；
2. 结构档位是对既有结构类条款（闭环禁令、呼应要求）的**授权高低**，不是替代（见 D.6，迭代 3 落地正文）；
3. 「非全指向性」配额与「保护资产条款」并存：正功能细节（人→动作→场景链）照旧，另加非功能细节（迭代 4 落位文体专项）。

## D.6 结构五档（structure_band 语义与纪律）

**为什么结构强度要随机**：技能对「结构」原本只有两种状态——该做的做、该禁的禁——于是每篇的结构完成度趋同（都做足闭环、都摆好呼应）。但真人文本的**结构紧致度本身方差极大**（有的首尾呼应、有的散着结束、有的中途改主意）；且结构层是最易被检出的层（StoryScope：架构层单独 93.2%，表层改写仅 −1.6pp）——**结构强度的方差才是最该模仿的「人类分布带」**。

| 档 | 结构设计权限 | 典型形态 |
|---|---|---|
| 1 | 不做结构设计 | 线性流水、无呼应、无收束、可在半途停下 |
| 2 | 仅一处结构动作 | 单点回扣**或**单点留白（二选一） |
| 3 | 中枢档（**非默认**） | 一处呼应 + 半收尾 |
| 4 | 两处结构动作 | 首尾弱呼应 + 一处主题留存 |
| 5 | 完整设计 | 可有回环、主题呼应、延迟揭示 |

**三禁令**：
1. **禁全批同档**——批内多篇的档位分布须覆盖多值（批级自检①）；
2. **禁「每篇都档 3」新点值**——把随机性改回确定性是最典型的回退；
3. **档位与体裁匹配**——应用文（zh-doc）上限 4、口语体（zh-s2）上限 3（体裁刚性：应用文的程式骨架与口语的松散常态不容许完整设计档）。

**低档豁免（与自检联动）**：档 1-2 的篇目**不得**按高档标准扣分——自检见 `selfcheck.md` 结构条款的按档授权行；否则自检会把随机性抹掉（生成侧刚拉开方差、自检侧又压回去）。

**length_target 附则（A2.4）**：抽签目标须匹配真人的**长度方差**而非仅落区间——批内多篇时，各篇 length_target 的离散度应接近该文体真人 SD（zh-essay 163 / zh-doc 368 / zh-s2 293 / en-essay 317 / en-tech 92 / en-fiction 367），全批长度扎堆即失败（批级自检③）。

## D.7 错字抽签纪律（防「配额本身成签名」）

实测教训：固定同音词表 + 每篇必错 = **错字类型聚簇**被严席整体识破（六例同簇）。v7 纪律：

1. **类型随机**：同音／形近／漏字／语序／标点五类型带内抽（typo_types 字段），禁全批单一类型；
2. **处数可为 0**：hard_typos 带 [0, 3]，真人并非每篇有错——**每篇必错是新指纹**；
3. **禁固定混淆词表**：错什么词由上下文自然决定，不查表；同批多篇的错字不得共享同一混淆对。
