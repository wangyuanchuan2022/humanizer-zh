# W2 说明性文章（register-W2）

> 档位细则文件，与 references/written-base.md（W0 共同原则+验收）配套使用；判定为 W2 后两者都须加载。

- 对比必须给具体数字或生活意象（「一分钟体」「从'8亿人吃不饱'到'14亿多人要吃好'」），禁「发生巨大变化」式抽象对比。
- 事实列举分号相连、句式整齐、每项自带 4-8 字小结论（「这是对失败的宽容」「矛盾凸显」）。
- 层次标引用段首判断句（「增强预见性，才能……」），不用「第一、第二」机械编号。
- 概念定性用「是A，是B」双判断句（「古树名木是记录自然生态变迁的'活化石'，是承载民族历史记忆的绿色'国宝'」）。
