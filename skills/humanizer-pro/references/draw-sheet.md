# 抽签表（draw sheet）——脚本化随机性的执行契约

> 本文件是 `draw-sheet.mjs` 的**契约文档**：字段、参数带、纪律。两者键名以本文 D.2 契约为单一事实源（改本文件必同步改脚本，verify 锚点同时锚两侧）。
> 依据：《humanizer 技能改进分析报告》§四主轴一 + 附录 D。核心论断：**确定性规则会把特征取值的离散度压平——真人写作的判别性不在单条特征上，而在离散度上**（实测：跨篇模具复用 6/12/4 处、错字同簇六例、句长/段长 SD 低于真人 37-45%）。

## D.1 四原则

1. **随机源固定且落盘**：每篇一份 draw sheet（JSON）含 seed；同 seed + 同 genre + 同 index 重跑得**逐字节一致**的结果 → 可复现、可审计、可回归。
2. **抽签只决定「用哪些手法、取值多少、结构多紧」，不决定内容**：内容仍受题材与事实约束（守主路由「永不编造具体信息」硬护栏）。
3. **带内抽样，禁锁点值**：取值来自 D.3 的人类分布带；**禁止把带的中位数当默认值**——「每篇都取中位」等于把随机性改回确定性。
4. **批级自检**：一批（≥3 篇）生成后，统计抽签结果分布是否覆盖带的多个取值，并跑跨篇模具复用检测（selfcheck 批级自检节）。

## D.2 九字段契约（JSON）

```json
{
  "seed": 20260920,              // 随机种子（日期或任意整数；须随稿落盘）
  "genre": "en-tech",            // 六文体之一
  "structure_band": 2,           // 结构强度档 1-5（见 D.6；体裁上限：应用文≤4、口语体≤3）
  "moves": ["announced_doubt", "non_goal_detail"],   // 本次启用的手法（池内抽 3-5，禁抽满、禁跨篇复用）
  "quotas": {                    // 配额实际取值（带内抽，禁点值）
    "aphorism_total": 1,         // 警句总数（带 0-2）
    "plain_paragraph": 2,        // 无发力平实段落数
    "first_person_per_1k": 3,    // 第一人称/千字
    "digits_per_1k": 5,          // 具体数字/千字
    "hard_typos": 1,             // 错字处数（带 0-3，允许 0）
    "typo_types": ["homophone"], // 错字类型（抽签：同音/形近/漏字/语序/标点）
    "non_goal_details": 2,       // 非指向细节（≥1：与主旨无支撑关系的材料）
    "half_used_sources": 1,      // 半用材料（≥1：引了只用一半/结论未采纳）
    "coinage": 1,                // 自造复合词/新造语（带 0-2，禁令上限 2，可为 0）
    "extended_metaphor": 0       // 巧喻装置（带 0-1，可为 0——有时抽到 0 个）
  },
  "ending_mode": "object_stop",  // close | half_close | open | object_stop（按体裁白名单抽：zh-doc 排除 open、zh-s2 排除 close，其余全池）
  "length_target": 780,          // 篇长目标（从该文体真人长度带抽，含 SD）
  "used_before": [],             // 同批已用句式模具（台账，禁复用）
  "notes": "档 2：仅一处结构动作（单点留白）；不设回环"
}
```

**执行纪律（write 操作）**：动笔前先出签——运行 `references/draw-sheet.mjs`（`node draw-sheet.mjs --seed <N> --genre <G> [--index <I>]`）照签执行；**draw sheet 随稿落盘**（含 seed 与实际取值）。无 shell 环境降级为**表格自抽 + 显式留痕**（在稿前写下九字段取值与理由，效力等同）。review/refactor 操作**不强制抽签**（诊断对象是既有文本）。

## D.3 参数带（真人臂数字带，来源：bands-from-human-corpus.md，HUMAN 臂只读统计）

> 逐文体；带=[min, max]（含离群），实施时**带内抽签**。⚠️ 标注行是代理指标（语义判断的启发式），只作方向参考。

| 文体 | 篇长（字/词） | 篇内句长 SD | 篇内段长 SD | 第一人称/千字 | 数字/千字 | 段尾短句率%（警句代理⚠️） |
|---|---|---|---|---|---|---|
| zh-essay | [697, 1258] | [12.6, 35.3] | [26.7, 90.3] | [0, 25.3] | [3.1, 19.6] | [0, 33.3] |
| zh-doc | [229, 1421] | [9.1, 111.5] | [21.9, 139.1] | [4.4, 35.4] | [2.1, 30.1] | [0, 50] |
| zh-s2 | [342, 1648] | [9.5, 88.1] | [13, 125.3] | [7.7, 52.5] | [3.5, 84.8] | [0, 66.7] |
| en-essay | [453, 1524]（词） | [5.8, 16.2] | [11.4, 54.4] | [16.3, 113.2] | [2, 23.1] | [0, 72.2] |
| en-tech | [551, 929]（词） | [7.8, 23.1] | [17.6, 61.4] | [2.9, 74.3] | [2.6, 54.4] | [0, 71.4] |
| en-fiction | [267, 1332]（词） | [5.6, 18.3] | [9.7, 74.5] | [0, 113.1] | [2.3, 19.5] | [12.5, 100] |

**长度规则**：抽签目标须匹配真人的**长度方差**而非仅落区间——批内多篇时，各篇 length_target 的**离散度**应接近该文体真人 SD（zh-essay 163 / en-essay 317 / en-fiction 367…），全批长度扎堆即失败。⚠️ 警句密度与错字率两行是代理指标（段尾短句率启发式），只作方向参考。

## D.4 手法池（moves；从「评审实证双清单」的有效手法提取）

| 手法名 | 内容 | 实证依据（评审原话节选） |
|---|---|---|
| `announced_doubt` | 主动交代不确定性／记忆模糊（"数字是估的"/"记不清哪年"/"it's round because I rounded"） | 判真人 HZ 篇的致胜证据；ChatGPT 判据 12 |
| `anticlimactic_close` | 反高潮／拒绝升华收尾 | `refused-thematic-summary` / `no-epiphany-ending` |
| `non_goal_detail` | 无用私人细节（不服务主题、不承担文学功能；"1215. Sandwich."） | `idiosyncratic-period-detail`；ChatGPT 判据 1 |
| `self_deprecation` | 自曝短板／愧疚（"improved the PR in every way except the one that mattered"） | `lingering guilt confession` |
| `life_runoff` | 生活流水与杂质（消费明细/错字/路人引语/物件收尾） | 消费明细流水、物件收尾（关东煮） |
| `plain_colloquial_close` | 平实口语收束（事实回扣收尾/对话收） | 「事实回扣收尾」「平实收尾」 |
| `texture_local` | 地域与实物纹理（Brookshire's / Culver's / ginja 巧克力杯） | 英文席点名认可 |

**改造条款（允许→带随机配额）**：Deferred／不闭环／瑕疵事件等既有「允许」类手法，v7 起进入 moves 池参加抽签——**只有成为配额才会稳定出现**（实测：判真人的 HZ 篇几乎都做了这些，但做与不做取决于模型当次发挥，跨篇出现率不稳定）。

**记忆模糊专项（A3.3）**：`announced_doubt` 进池（上表首行）；**禁全篇精确时间线**——同篇内至少一处时间/数字以模糊形态出现（约/大概/哪年来着/记不清），抽到本手法时执行。

## D.4b 细节与文献的非全指向性（三档配额）

**问题**：AI 让每个细节、每条引文都服务于主旨——「每一个细节单独看都合理，但放在一起有一种作者为了证明自己经历过这件事而主动提供证据的感觉」（外部评审原话）；应用文评审的 AI 判据同样写着「数字密铺且每处细节均承重」。真人反思文常见的恰恰相反：**引了但只用一半、提到就搁下、材料与主旨只部分相关**。

| 配额 | 要求 | 例 |
|---|---|---|
| **非指向配额**（non_goal_details，带 [1,3]） | 每篇 ≥1 处材料/细节与主旨**无支撑关系** | 提及某书某事后搁下不回收；写一段与主题无关的侧枝 |
| **半用配额**（half_used_sources，带 [1,2]） | ≥1 处文献/数据**只被部分使用** | 引了某观点但结论未采纳；提出材料后自我怀疑「这个例子其实也可以反过来说」 |
| **未消化痕迹**（随 half_used 出现，非独立配额） | 允许未完成处理 | 「这本书我其实没读完」「这段我到现在也没想明白」「当时记的笔记现在看不懂了」 |

**文体专项**：
- **反思/议论文（zh-essay / en-essay）**：**文献不必全部指向主旨**——材料的价值可以是它的存在本身，而非它对论点的支撑；引用后搁置、部分采纳、提出后存疑都是合法形态。
- **应用文（zh-doc）**：数字与事实不必每处承重；允许与结论无关的例行数据（人数、时间、批次）自然在场。
- **小说（en-fiction / 中文小说）**：与「保护资产条款」配平——保护资产要求的「人→动作→场景具体链」是**正功能细节**，本配额要求的是**非功能细节**，两者须同时存在（实测：判真人的 HZ 篇普遍有非功能细节，被判 AI 的普遍没有）。

**执行**：抽签时 non_goal_details/half_used_sources 已在 quotas 输出；写作时落实为具体材料选择，自检时人工核对「非指向是否实质」（装饰性跑题不算）。

## D.5 与既有条款的三关系

1. 本机制**不新增禁令**，而是把既有条款（W0 系列配额、九测、保护资产、Deferred 等）的值域**从点值改为可抽样的带**；
2. 结构档位是对既有结构类条款（闭环禁令、呼应要求）的**授权高低**，不是替代（见 D.6，迭代 3 落地正文）；
3. 「非全指向性」配额与「保护资产条款」并存：正功能细节（人→动作→场景链）照旧，另加非功能细节（迭代 4 落位文体专项）。

## D.6 结构五档（structure_band 语义与纪律）

**为什么结构强度要随机**：技能对「结构」原本只有两种状态——该做的做、该禁的禁——于是每篇的结构完成度趋同（都做足闭环、都摆好呼应）。但真人文本的**结构紧致度本身方差极大**（有的首尾呼应、有的散着结束、有的中途改主意）；且结构层是最易被检出的层（StoryScope：架构层单独 93.2%，表层改写仅 −1.6pp）——**结构强度的方差才是最该模仿的「人类分布带」**。

| 档 | 结构设计权限 | 典型形态 |
|---|---|---|
| 1 | 不做结构设计 | 线性流水、无呼应、无收束、可在半途停下 |
| 2 | 仅一处结构动作 | 单点回扣**或**单点留白（二选一） |
| 3 | 中枢档（**非默认**） | 一处呼应 + 半收尾 |
| 4 | 两处结构动作 | 首尾弱呼应 + 一处主题留存 |
| 5 | 完整设计 | 可有回环、主题呼应、延迟揭示 |

**三禁令**：
1. **禁全批同档**——批内多篇的档位分布须覆盖多值（批级自检①）；
2. **禁「每篇都档 3」新点值**——把随机性改回确定性是最典型的回退；
3. **档位与体裁匹配**——应用文（zh-doc）上限 4、口语体（zh-s2）上限 3（体裁刚性：应用文的程式骨架与口语的松散常态不容许完整设计档）。

**低档豁免（与自检联动）**：档 1-2 的篇目**不得**按高档标准扣分——自检见 `selfcheck.md` 结构条款的按档授权行；否则自检会把随机性抹掉（生成侧刚拉开方差、自检侧又压回去）。

**length_target 附则（A2.4）**：抽签目标须匹配真人的**长度方差**而非仅落区间——批内多篇时，各篇 length_target 的离散度应接近该文体真人 SD（zh-essay 163 / zh-doc 368 / zh-s2 293 / en-essay 317 / en-tech 92 / en-fiction 367），全批长度扎堆即失败（批级自检③）。

## D.7 错字抽签纪律（防「配额本身成签名」）

实测教训：固定同音词表 + 每篇必错 = **错字类型聚簇**被严席整体识破（六例同簇）。v7 纪律：

1. **类型随机**：同音／形近／漏字／语序／标点五类型带内抽（typo_types 字段），禁全批单一类型；
2. **处数可为 0**：hard_typos 带 [0, 3]，真人并非每篇有错——**每篇必错是新指纹**；
3. **禁固定混淆词表**：错什么词由上下文自然决定，不查表；同批多篇的错字不得共享同一混淆对。

## D.8 跨篇模具黑名单（used_before 台账）

同批生成多篇时维护「已用句式模具」台账（会话内），以下模具为**实测已暴露形态**，任何批次**禁用**（正则形态登记，生产侧不出现同构句式）：

| 模具形态（正则） | 实测出处 |
|---|---|
| `wearing a .{0,20}(costume|disguise|lanyard)` | en-tech HZ 臂 3 篇 / RAW 0 / 真人 0（语料层复核） |
| `(caveat|verdict|stance), so you can \w+ me` | en-tech 严席点名 12 处 |
| `If I compress .{0,30} into` | en-tech 4 处收尾盘点 |

新增模具发现即登记本表（批级自检②的输出回流）。

## D.9 点值白名单（A1.3：保留点值的配额及理由）

v7 配额纪律：**人味类配额**（要制造的特征量——做多少、多密、放哪）一律带化抽签；**禁令类配额**（防 AI 指纹的上限——越多越像 AI）保留点值。指纹没有「带」：警句 3 句就是比 2 句像 AI，不存在「警句带内随机 1-4 句」的写法。白名单登记：

| 保留点值的条目 | 文件 | 理由 |
|---|---|---|
| 金句/警句全篇 ≤2 | selfcheck 测② / register-W1 #6 | 禁令类（段段金句是首位定罪指纹）；**位置分布**已带化（跨段配额+平段配额） |
| 段首小标题 ≤2 且不同型 | register-W1 #3 | 禁令类（骨架同构指纹） |
| 二元对照 ≤3、连续两段禁同型 | written-base W0.6 / register-W1 #5 | 禁令类（切分句式指纹） |
| 价值升华 ≤2 / 认识弧 ≤2 | written-base W0.9/W0.10 | 禁令类（升华指纹；变体同罪） |
| 引用源每千字 ≤2 | selfcheck 测③ | 禁令类（堆引证指纹） |
| sepia vendor 原文保真段 | style-pass/narrative-pass 等编译件 | 全量保真纪律（用户 2026-09-12 规则），不改写为带 |

**已带化条目**（对照，证明清理完成）：警句总数 [0,2]（抽签 quotas——上限 2 的禁令语义保留，实际取值带内抽）、表情/颜文字 [0,2]（colloquial-base S0.2，允许 0）、错字处数 [0,3] + 类型随机（D.7，**篇级口径**）、平段（抽签 quotas）、非指向/半用（抽签 quotas）、警句位置分布（跨段配额）、结构档位（D.6）、长度（D.3）、手法选择（D.4）、造词 coinage [0,2] 与巧喻 extended_metaphor [0,1]（D.2）。
