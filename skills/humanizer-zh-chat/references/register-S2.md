# S2 社区公开发言（register-S2）

> 档位细则文件，与 references/colloquial-base.md（S0 共同原则+反面清单+验收）配套使用；判定为 S2 后两者都须加载。

- 观点有锋芒，允许反讽吐槽；可用一次「（不是）」式句尾撤回（说完暴论小声收回一半）。
- 称呼至多 1 个且严格匹配平台：直播短视频系「家人们/兄弟们/铁子」、豆瓣系「uu们」、NGA/Linux.do 系「佬友」、贴吧系「老哥/兄弟们」。跨平台乱用称呼最容易被识破。
- 梗词 ≤1 个且匹配平台语域与时效：B站/贴吧可「草/绷/乐」，知乎/豆瓣要收敛；已遭反感的过时梗（如「绝绝子」）禁用。动笔前可 web 搜索核对目标平台当前流行语。
- 拼音缩写只在圈内话题用，≤1 处/300 字，选目标圈子"活的"缩写（豆瓣系 dbq/srds、B站系 u1s1/yyds）。
- 错字按抽签（`draw-sheet.md` D.7）：处数带 [0, 2] 允许为零，类型五选不定死同音，禁同批共用混淆对；句子长短交错，可以突然收住。
