# humanizer-zh-chat — 中文口语档（S1/S2/S3）

本包是中文口语场景的**完整作战手册**：口语的人味 = 不完美 + 有意图，错误要错得像真人，元素要低频、位置随意。

## 加载序（动笔前读完，缺一不可）

1. `references/colloquial-base.md` — S0 共同原则 9 条（错字配额/表情点缀/瑕疵事件化/情绪失配/通信钩挂/省略优先/联想序）+ 口语反面清单 + 验收清单
2. `references/register-S1.md` / `register-S2.md` / `register-S3.md`（按判定档位读对应一件）— 档位细则与语域天花板
3. `references/zh-hans.md` — 简体中文校准（AI 高频词/句法模板/句长节奏/白名单；本包只需其口语相关节，但全文可作参考）

档位判定：S1 朋友私聊群聊 / S2 贴吧知乎B站微博豆瓣评论回复 / S3 向老师上级汇报·学习群·工单·求助帖。判定依据：用户明示 > 文本特征；判不出默认 S3 并注明。

## 工作流（write/refactor 通用）

1. 按加载序读文件后，通读标记 AI 痕迹（zh-hans §1-2 词表与句式 + 底线规则的中文形），同时按 S 档正向策略规划人味元素。
2. 0b 代写：任务点标注表（合并/错位/加重/轻放/弃）→ 保护资产清单与结构变化留档 → 材料核验。
3. 写作执行 S 档正向策略：低频真人信号（语气词/括号补充/元互动/瑕疵事件优先）、错字只错高频混淆对、S0.6 加重位+轻放位、S0.9 联想序。
4. 自检：跑 `references/selfcheck.md` 的口语档分流测（①④⑤⑥，②⑦按档位配额换算）——该文件在本包 references/ 内。
5. 验收对照 colloquial-base 末节清单 + 红队自评（AI 概率 >40% 修订一次）。

## 口语反面清单速览（全文见 colloquial-base）

每句必加 emoji；错字过密；装疯卖傻式夸张；强行网梗过时梗；表情括号固定位置模板化；「欢迎评论区留言」模板互动；每句「呃嗯」伪结巴；总结句升华收尾；公文标点密度；句长节奏均匀；任务点逐条对应段落（结构镜像）；情绪全程配平；中立化自指；通篇无一处随意/省略/跳 tone；S3 把全局语域拉到闲聊档（头号翻车点）。

## 接缝

- 文本中夹带长篇书面段落且需深改 → 该部分按 `humanizer-zh-write` 处理（skill 加载）。
- 繁体台湾场合 → 改用 `humanizer-zh-hant`。
- 平台流行语时效存疑时可用 web search 核对目标平台当前用语。

## 伴生脚本与抽签

- **write/recreate 动笔前先抽签**：运行 `node references/draw-sheet.mjs --seed <N> --genre zh-s2`（批内多篇加 `--index <I>`）出签照做；**draw sheet 随稿落盘**。无 shell 环境按 `references/draw-sheet.md`（契约文档：字段/参数带/错字纪律/模具黑名单）表格自抽并显式留痕。review/refactor 不强制抽签。
