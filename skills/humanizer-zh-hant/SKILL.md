# humanizer-zh-hant — 繁體中文（台灣場合）校準

本包是繁體台灣場合的**完整語言校準**，全量保真改編自 sepia `languages/zh.md`。簡體文本**不加載本包**（簡體用 humanizer-zh-chat / humanizer-zh-write，其 zh-hans.md 與本包互斥；簡體文案即使在台灣場合也保持自身慣例）。

## 加載與適用

1. 讀 `references/zh-hant.md` 全文——它是 style-pass 步驟的繁體校準：§0 台灣規範（MOE-PUNCT-2008 標點各行 / EY-NUMERALS-2004 數字原則；場域規則而非作者身份信號）、§1/1b/1c 量化表（HC3 句長 SD、台灣新聞人類側出現率 T、三模型機器側 M——全部數字僅作方向參考，無逐段閾值）、§2 獵查表、§3 恢復清單、§4 編輯啟發、§5 非信號清單、§6 證據邊界。
2. 按文本類型配對應場景包的結構/文體規則：新聞/報導類 → `humanizer-pro`（journalism 領域與本包 §0 標題/歸因動詞行配合）；小說 → `humanizer-fiction`；其餘按 humanizer 主路由表。
3. 場域未知時：作者自身樣本決定規範行是否適用；場域已知且非台灣時，場域優先，本包 §0 規範行全部不適用（§5 台灣詞彙守衛行除外，其作用域獨立）。

## 鐵律

- 每個數字都是「觀察到一次的方向」，不是校準常數；無任何行授權逐段 cutoff。
- 引文內標點與文字承重不改（含句尾符號在引號內外的既有位置）；程式碼/指令/URL/檔名/版本字串永不觸碰。
- 台灣詞彙守衛（視頻/軟件/質量）僅在「台灣場域 + 作者樣本不用這些詞」時修，屬語域失配而非 AI 信號。
